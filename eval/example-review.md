# 同梱例の意味保存レビュー

確認日: 2026-09-08
評価者: Codex による文書レビュー

[変換例](../examples/before-after.md) と [日本語向け変換規則](../references/japanese-rules.md) を、
[意味保存チェックリスト](semantic-fidelity-checklist.md) に沿って照合した記録です。
原文と、各例で明示した入力の文脈を根拠にしています。
実際のモデル出力を使った反復試験、独立した人による評価、読み手の理解度試験は実施していません。

## 変換例

「悪い短文化」は不合格を説明するための例として、採用する改稿と区別します。

| 例 | 原文から改稿へ保持した意味 | 改稿から入力への照合 | 判定 |
|---|---|---|---|
| 1 | 金曜の予定、木曜17時の承認期限、期限に間に合わなければ翌週火曜へ延期する可能性 | 予定と可能性を確定に変えていない。承認期限は原文の分岐条件に対応 | PASS |
| 2 | 今回の設計、RPO、正式名、定義、15分 | 各文が原文の設定または括弧内の定義に対応 | PASS |
| 3 | 現時点の暫定的判断、総合的な考慮の必要性、将来の要件変更への留意 | 選定理由や見直し予定は追加していない。削ったのは挨拶・称賛・導入 | PASS |
| 4 | 開く、接続先を変更、保存、テストの順序。失敗時にログ確認、認証エラーなら再発行 | 各操作と分岐が原文に対応。再テストや成功を完了条件として追加していない | PASS |
| 5 | 1人4冊まで、翌日起算の10日間、表紙の「館内用」は貸出不可、期限が休室日なら次の開室日 | 改稿の4つの規則が原文に対応。上限・起算日・例外を補完していない | PASS |
| 6 | 読込時の検証、空値ならエラー、テストでの確認、各パスと行範囲 | 3つの主張と2つの参照先が原文に対応 | PASS |
| 7 | 指定関数の修正、空値をエラーにする条件の維持、パスと行範囲 | 操作対象と条件を保持し、番号は元の参照先だけを指す | PASS |
| 8 | キャッシュ使用の方針と例外、再利用の効果、事前確認と有効化の条件 | 本文の語句と順序は同じで、改行だけを変更 | PASS |
| 9 | 保存後に再起動する順序、保存前の再起動で変更が失われること | 原文と改稿が同一 | PASS |

例5の「悪い短文化」は、貸出上限・日数・貸出不可の条件・休室日の扱いを落とすため FAIL です。

## 日本語向け変換規則

| 節 | 照合対象と確認結果 | 判定 |
|---|---|---|
| 1 | A案が「比較的妥当と考えられる」こと、経緯と複数観点、一概に言えないという留保を保持。別案や例外は追加していない | PASS |
| 2 | 金曜の反映、木曜までに承認がなければ延期する条件を保持 | PASS |
| 3 | RPOを決めることと、許容するデータ損失の範囲を示す「目標値」という定義を保持。正式名の提示は入力にある場合に限定 | PASS |
| 4 | 担当者・反映先・復旧先の根拠は明示した文脈にある。操作順と問題発生時の条件は原文にある。文脈がない場合は原文を保持し、確認を改稿から分離 | PASS |
| 5 | 指示語の2つの参照先は明示した文脈にある。影響関係は原文にある。文脈がない場合は具体名を追加しない | PASS |
| 6 | 利用者の呼称だけを統一。アカウント作成、更新対象の「会員情報」、操作順を保持 | PASS |
| 7 | 単独の構造テンプレートであり、原文との比較例ではない。適用時には入力にある項目だけを使用 | 対象外 |
| 8 | 一覧と段落を選ぶための規則であり、原文との比較例ではない | 対象外 |
| 9・可能性 | 原文をそのまま保持し、断定や検証の約束を追加しない。「悪い削減」の断定は FAIL | PASS |
| 9・件数 | 10ケース中8ケースという件数は入力の計測記録にある。未検証の環境については不明のまま保つ | PASS |
| 10 | 2つのコマンドを変更せず、最初のコマンドが失敗した場合だけ次を実行する条件を保持 | PASS |
| 11 | 独立した比較例はなく、変換例6・7でパス・行範囲・主張との対応を確認 | 対象外 |
| 12 | 独立した比較例はなく、変換例8・9で改行による語句・順序の保存を確認 | 対象外 |

## 今後の改訂時

例を変更したら、原文の重要情報が残るかと、改稿の各主張に入力の根拠があるかを再確認します。
文脈付きの例では、その文脈を外しても同じ具体名や数値を出してよいとは判断しないでください。
自動リントの成功や、この表の PASS を、利用者に対するスキルの有効性の証明として扱わないでください。
